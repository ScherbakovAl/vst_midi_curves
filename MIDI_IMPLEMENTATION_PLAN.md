# План реализации MIDI коммуникации для VST MIDI Curves Plugin

## 🎯 Цель
Создать рабочую MIDI коммуникацию для VST MIDI Curves Plugin, включающую:
- Прием MIDI сообщений от внешних устройств и приложений
- Обработка velocity через кривые
- Трансляция MIDI сообщений для других приложений
- Поддержка как standalone, так и VST3 режимов

## 🔧 Технические детали

### Основные компоненты:
1. **MidiProcessor** - основной MIDI обработчик
2. **VelocityCurveProcessor** - процессор скорости с кривыми
3. **MidiRouter** - маршрутизация MIDI сообщений
4. **MidiInputHandler** - обработка входящих MIDI событий
5. **MidiOutputHandler** - отправка исходящих MIDI событий

### MIDI события для обработки:
- Note On/Off (основная задача)
- Velocity processing (основная задача)
- CC (Control Change) - опционально
- Pitch Bend - опционально
