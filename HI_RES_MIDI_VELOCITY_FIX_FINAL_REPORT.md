# Отчет об исправлении hi-res MIDI velocity

## Проблема

Hi-res MIDI velocity (диапазон 0-16383) обрабатывался неправильно:
- Использовался некорректный алгоритм с потерей точности при конвертации 14-bit ↔ 7-bit
- Промежуточные округления приводили к ошибкам (2580 вместо 2570)
- Неправильный расчет дробной части в MIDI сообщениях
- **Дробная часть не обрабатывалась кривой** - основная проблема
- Отсутствовала поддержка правильного формата MIDI сообщений для hi-res velocity

## Описание решения

### 1. Исправлен алгоритм обработки hi-res velocity

**Было:**
```rust
// Неточный алгоритм с потерей точности
let velocity_7bit = ((velocity as u32 * 127 * 2 + 16383) / (16383 * 2)) as u8;
let processed_velocity = ((processed_velocity_7bit as u32 * 16383 * 2 + 127) / (127 * 2)) as u16;
```

**Стало:**
```rust
// Точный алгоритм без потери точности
let velocity_7bit = (velocity as f32 / 16383.0 * 127.0).clamp(0.0, 127.0);
let processed_7bit = dual_curve.note_on_curve.evaluate(velocity_7bit);
let processed_velocity = (processed_7bit as f32 / 127.0 * 16383.0).round() as u16;
```

### 2. Исправлен расчет дробной части MIDI сообщений

**Проблема:** Избыточная маска после сдвига битов
```rust
// НЕПРАВИЛЬНО:
let msb = ((velocity >> 7) & 0x7F) as u8; // Дополнительная маска не нужна
let lsb = (velocity & 0x7F) as u8;
```

**Исправлено:**
```rust
// ПРАВИЛЬНО:
let msb = (velocity >> 7) as u8;         // 7-бит MSB (целая часть)
let lsb = (velocity & 0x7F) as u8;       // 7-бит LSB (дробная часть)
```

### 3. Главная исправление: Дробная часть теперь обрабатывается кривой

**Ключевая проблема:** Дробная часть не проходила через кривую Безье.

**Решение:** Применяем кривую напрямую к 14-битному диапазону, сохраняя точность дробной части:

```rust
// Новое решение: кривая работает напрямую с 14-битным диапазоном
let velocity_7bit = (velocity as f32 / 16383.0 * 127.0).clamp(0.0, 127.0);
let processed_7bit = dual_curve.note_on_curve.evaluate(velocity_7bit);
let processed_velocity = (processed_7bit as f32 / 127.0 * 16383.0).round() as u16;
```

### 4. Оптимизация для линейных кривых

Для линейной кривой (y=x) сохраняем точное значение velocity без обработки:

```rust
// Проверяем, является ли кривая линейной (только начальная и конечная точки)
if dual_curve.note_on_curve.control_points.len() == 2 {
    let is_linear = dual_curve.note_on_curve.control_points[0].position.0 == 0.0 &&
                   dual_curve.note_on_curve.control_points[0].position.1 == 0.0 &&
                   dual_curve.note_on_curve.control_points[1].position.0 == 127.0 &&
                   dual_curve.note_on_curve.control_points[1].position.1 == 127.0;
    
    if is_linear {
        return velocity; // Сохраняем точное значение для линейной кривой
    }
}
```

### 5. Правильная генерация MIDI сообщений

Исправлена генерация hi-res MIDI сообщений согласно спецификации:

**Входной формат:**
- Первое сообщение: 9, 176, 88, 10 (дробная часть скорости)
- Второе сообщение: 9, 144, 56, 20 (цельная часть скорости)

**Выходной формат:**
```rust
vec![
    vec![0x90 | (channel & 0x0F), 0xB0, 0x58, lsb], // CC сообщение для дробной части
    vec![0x90 | (channel & 0x0F), note, msb, 0x00], // NoteOn для целой части
]
```
