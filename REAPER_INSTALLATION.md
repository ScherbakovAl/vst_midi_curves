# Руководство по установке VST3 плагина MidiCurves в Reaper

## Проблема
VST3 плагин не загружался в Reaper из-за неправильной структуры файлов.

## Решение

### 1. Правильная структура VST3 плагина
VST3 плагин должен иметь структуру:
```
PluginName.vst3/
└── Contents/
    ├── Info.plist          # Метаданные плагина
    ├── Resources/          # Дополнительные ресурсы
    └── [Platform]/
        └── PluginName      # Исполняемый файл плагина
```

### 2. Установка в Reaper

#### Linux
1. Скопировать папку `MidiCurves.vst3` в одну из следующих директорий:
   - `~/.vst3/` (рекомендуется)
   - `/usr/lib/vst3/`
   - Любая другая папка, указанная в настройках Reaper

2. Перезапустить Reaper или обновить список плагинов:
   - **Опции** → **Настройки** → **Плагины** → **VST**
   - Нажать "Сканировать все"

#### macOS
1. Скопировать `MidiCurves.vst3` в:
   - `~/Library/Audio/Plug-Ins/VST3/`
   - `/Library/Audio/Plug-Ins/VST3/` (для всех пользователей)

2. Перезапустить Reaper и обновить список плагинов

#### Windows
1. Скопировать `MidiCurves.vst3` в:
   - `C:\Program Files\Common Files\VST3\`
   - Пользовательскую папку: `%APPDATA%\VST3\`

2. Обновить список плагинов в Reaper

### 3. Проверка установки
1. Открыть Reaper
2. Создать новый трек
3. Нажать **Insert** → **VST** → **MidiCurves**
4. Если плагин загружается корректно, вы увидите интерфейс с кривыми Безье

### 4. Возможные проблемы и решения

#### "Плагин не найден"
- Проверить правильность пути установки
- Убедиться, что файл `Info.plist` присутствует
- Проверить права доступа к файлу плагина

#### "Ошибка загрузки плагина"
- Проверить логи Reaper в **View** → **Console**
- Убедиться, что все зависимости установлены
- Попробовать пересобрать плагин

#### "Плагин не отображается в списке"
- Обновить кэш плагинов: **Options** → **Settings** → **Plugins** → **Rescan**
- Проверить путь в настройках VST3

### 5. Отладка
1. Запустить Reaper из терминала для просмотра ошибок:
   ```bash
   reaper
   ```

2. Проверить системные зависимости:
   ```bash
   ldd build/midi_curves_v0.1.0/MidiCurves.vst3/Contents/x86_64-linux/MidiCurves
   ```

3. Проверить права доступа:
   ```bash
   chmod +x build/midi_curves_v0.1.0/MidiCurves.vst3/Contents/x86_64-linux/MidiCurves
   ```

## Дополнительная информация

### Пути VST3 в различных DAW
- **Reaper**: Настройки → Плагины → VST
- **Logic Pro**: ~/Library/Audio/Plug-Ins/VST3/
- **Pro Tools**: Плагины VST3 не поддерживаются
- **Cubase**: Cubase/VST3/

### Метаданные плагина
Info.plist содержит:
- Идентификатор производителя и плагина
- Тип плагина (VST3)
- Поддерживаемые форматы
- Версию плагина

### Размер плагина
Размер 4.5MB является нормальным для Rust-based плагина с GUI (egui), включены:
- Базовые библиотеки Rust
- GUI библиотеки
- MIDI обработка
- Интерполяция кривых Безье
