```rust
fn process(&mut self, /* ... */) -> ProcessStatus {
    while let Some(event) = context.next_event() {
        match event {
            NoteEvent::NoteOn { velocity, .. } => {
                // Применяем кривую Безье к velocity
                let processed_velocity = {
                    let mut curve = self.curve_processor.lock().unwrap();
                    curve.evaluate(velocity * 127.0) / 127.0
                };
                // Отправляем обработанное событие

        }
    }
```

## 🎯 Использование

### Как VST3 плагин:
1. Скомпилировать проект: `cargo build --release`
2. Скопировать `.so/.dylib` файл в папку VST3 плагинов
3. Загрузить в DAW: "MIDI Curves"

### Как standalone приложение:
1. Запустить: `./target/release/midi_curves`
2. Использовать GUI для настройки кривых
3. Подключить MIDI устройства
