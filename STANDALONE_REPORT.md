## 🏗️ Архитектура Standalone приложения

```
src/main.rs
├── MidiCurvesApp (главная структура)
│   ├── curve: Arc<Mutex<BezierCurve>> - обработка кривых
│   ├── preset_manager: Arc<Mutex<PresetManager>> - управление пресетами
│   ├── midi_state: MidiState - состояние MIDI
│   └── selected_point: Option<usize> - выбранная точка
├── GUI компоненты
│   ├── draw_main_ui() - главный интерфейс
│   ├── draw_curve_editor() - редактор кривых
│   ├── draw_test_panel() - панель тестирования
│   ├── draw_presets_panel() - управление пресетами
│   └── draw_midi_panel() - MIDI настройки
├── Обработка взаимодействий
│   ├── handle_curve_interaction() - обработка мыши
│   ├── screen_to_world() - конвертация координат
│   └── world_to_screen() - обратная конвертация
└── Отрисовка
    ├── draw_curve() - отрисовка кривой
    ├── draw_grid() - сетка
    └── draw_control_points() - контрольные точки
```

## 📦 Встроенные пресеты

1. **Linear** - Линейная кривая (y = x)
2. **Soft S-Curve** - Мягкая S-образная кривая
3. **Exponential** - Экспоненциальная кривая
4. **Inverse Exponential** - Обратная экспоненциальная
5. **Sigmoid** - Сигмоидная кривая
6. **Hard Step** - Жесткая ступенька
7. **Gentle Curve** - Плавная кривая
8. **Aggressive Curve** - Агрессивная кривая

## 🔧 Технические детали

### Зависимости
- **eframe 0.28** - кроссплатформенный GUI
- **egui 0.28** - immediate mode UI
- **serde + serde_json** - сериализация пресетов
- **kurbo 0.11** - математика кривых Безье
- **dirs 5.0** - директории конфигурации

### Ключевые компоненты
- **BezierCurve** - обработка кривых с LUT оптимизацией
- **PresetManager** - управление пресетами с файловым хранилищем
- **ControlPoint** - контрольные точки с касательными
- **MidiCurvesApp** - главное приложение
