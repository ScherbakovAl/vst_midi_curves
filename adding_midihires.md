Приложение создано согласно условиям из @/ARCHITECTURE.md

К имеющимся возможностям приложения необходимо добавить возможность обработки MIDI сообщений высокого разрешения (hi-res MIDI). В standalone версии приложения реализована обработка скорости MIDI сообщений для событий нот "note on" и "note off". Необходимо добавить возможность переключиться в режим работы с MIDI высокого разрешения с помощью кнопки переключения в интерфейсе → необходимо добавить кнопку в интерфейс. Сообщения MIDI высокого разрешения позволяют передавать 14-битный диапазон значений (в отличие от 7-битных значений стандартного MIDI). Это диапазон 0-16256. Сообщения MIDI высокого разрешения формируются из двух последовательных четырёхбайтных сообщений. Первое сообщение (префикс) представляет собой команду cc#88, содержащую в последнем байте 7 младших бит данных скорости. За ним следует обычное сообщение, содержащее 7 старших бит значений скорости. Документ, дополняющий описание MIDI высокого разрешения: @/MIDI_HIRES.md

Обработка значений: следует объединить старшие и младшие биты, получить 14-битное число. Это число необходимо правильно нормализовать для обработки через кривую на графике. Число следует обработать так, чтобы не потерять 14-битное разрешение. Далее (после обработки) необходимо обратно нормализовать в 14-битное число, сформировать из него старшую и младшую части. Затем необходимо отправить на выход два полученных сообщения в таком же виде (как получены: префикс cc#88 с младшей частью и обычное сообщение, где указаны канал, номер ноты, тип noteon или noteoff, старшая часть), только заменив значения скорости на вычисленные (также как и со стандартным MIDI разрешением) старшие и младшие части.
