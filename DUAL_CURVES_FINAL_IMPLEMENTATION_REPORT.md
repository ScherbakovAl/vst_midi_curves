# Отчет о реализации двойных кривых для MIDI событий

## 📋 Краткое описание задачи

Была поставлена задача модифицировать VST MIDI Curves плагин для использования отдельных кривых для разных типов MIDI событий:
- Отдельная кривая для Note ON событий
- Отдельная кривая для Note OFF событий

Требовалось создать вкладки в GUI для переключения между кривыми и редактирования их независимо.
